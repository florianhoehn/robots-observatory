RobotsObservatory

You probably found this URL in an access log. Here is exactly what this bot did, and how to stop it.

RobotsObservatory is a research crawler that measures how the web declares its policy toward AI agents. It reads robots.txt and ten well-known policy files from fixed lists of sites and publishes the aggregate result as an open dataset: 463 sites weekly, and occasionally a wider survey of about 16,000.

It does not read your pages. It requests only files that exist to be read by machines. It never touches anything behind a login, never submits a form, never solves a CAPTCHA, and never works around a paywall.

How to stop it

Put this in your robots.txt:

User-agent: RobotsObservatory
Disallow: /

We read robots.txt once — that file is exempt from robots.txt rules under RFC 9309, which is the only way any crawler can learn it has been told to stop — and then request nothing else from your host, this run or any future one.

No custom directive to learn, nothing to email, and nothing for us to approve.

What it requested

Per host, per run, exactly twelve requests. Four of them — security.txt, ads.txt, gpc.json and humans.txt — are not about AI. They are controls, so the AI-specific numbers can be read against something:

PathCountWhy
/robots.txt2once per requester identity, to see whether declared policy varies by who asks
/llms.txt1a guide written for AI readers
/ai.txt1training opt-out convention
/.well-known/tdmrep.json1TDM Reservation Protocol
/.well-known/security.txt1RFC 9116 security contact — a control, not an AI signal
/ads.txt1IAB authorised sellers — a benchmark for machine-readable adoption
/.well-known/gpc.json1Global Privacy Control
/humans.txt1the human counterpart to robots.txt — a control
/.well-known/agent-card.json1A2A Agent Card — a site describing itself to agents
/.well-known/ai-catalog.json1AI Catalog — domain-level discovery for MCP and A2A
/.well-known/agent.json1the pre-1.0 A2A path, so a zero at the current one is interpretable

Twelve requests per host, per run. Spread over about seventeen seconds, with 1.5 seconds between requests to any one host, thirty hosts in flight at a time — a figure that governs how many different sites are read in parallel, never how fast any one of them is asked. That is less traffic than one person loading one page. A host whose probe fails is retried once after a pause, so a transient timeout is not recorded as a policy fact.

The two user-agents

One declares itself. The other is a browser-shaped control, used to detect sites that serve different policy to bots than to browsers — it still carries full contact details, so no request this project makes is anonymous:

RobotsObservatory/1.0 (+https://florianhoehn.github.io/robots-observatory/bot/)

Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko)
  Chrome/141.0.0.0 Safari/537.36
  + From: and X-Observatory-Contact: headers pointing here

We never impersonate another operator. No GPTBot, no ClaudeBot, no CCBot, no third party's token, ever.

What it stores

  • Status codes, response times, content hashes, and all response headers.
  • The body of every path listed above — including whatever is returned instead of one: a 404, an error page, a cookie-consent wall, a CAPTCHA. Those are evidence about how the web treats automated readers, and they are this study's subject just as much as a policy file is.
  • Set-Cookie values are the one redaction. They carry nothing but an anonymous session id and do not belong in a public archive.
  • No page body exists to retain, because no page is ever requested.

The aim is that a future question can be answered from the stored responses rather than by requesting anything from you a second time. Keeping less would mean coming back.

Removal from the published dataset

Blocking us in robots.txt stops the crawling. If you also want a host's rows removed from the published dataset — which names thousands of sites and will stay online indefinitely — open an issue and it will be removed. You will not be asked to justify it.

Who and why

A personal research project. Every argument about AI agents and the web runs on anecdote, because there is no public baseline for what sites actually declare. This builds one, in the open, under CC0.

The collector is two readable Python files. The claim that it only ever requests the paths above is checkable from the source, not just asserted — read it.
