What this says

Everyone is arguing about whether AI agents should pay for access to the web. Almost nobody is asking for money: … of these sites carry any licensing or pay-per-crawl signal at all.

But a fifth of them have written a document for the agents. So far the web's answer to automated readers is not a toll booth — it is documentation.

That is one snapshot from one vantage, and the panel is more than half commerce. The limits matter as much as the numbers.

Why the raw number is published but not reported

A straight hash comparison says the files differ on … of the panel. That number is almost entirely artefact: two error pages, or two cookie-consent pages, whose bytes differ only because of an embedded nonce. It is kept here so the gap between it and the real figure stays visible.

Genuine identity-dependent policy reproduces on two hosts. rakuten.co.jp serves a declared bot 490 bytes of rules and a browser a 51-byte stub; telegraph.co.uk serves 3,228 bytes against 914.

Method

The panel

Tranco list 467YX, 18 October 2026, top 1000 — screened by hand to 463 content websites. 537 were excluded, mostly because they are not websites: CDN and asset hosts, cloud and API endpoints, ad and analytics serving domains, DNS and certificate infrastructure. 31 of the top 50 are not websites anyone reads. Tranco ranks domains by machine lookups, and one human page load triggers a dozen of those.

Every decision is published per host, so you can disagree with any single row rather than audit a rule. 17 hosts are excluded because this vantage cannot resolve them — a property of the measuring machine, not of those hosts, and documented as such.

What was requested

Five requests per host: /robots.txt twice, once per identity, then /llms.txt, /ai.txt and /.well-known/tdmrep.json once each. A host whose probe fails is retried once after a pause, so a transient timeout is not recorded as a policy fact.

No page was ever fetched. Only files the web publishes for machines to read, so no request was one a host asked bots not to make. That claim is checkable from two readable source files rather than merely asserted.

No model in the measurement path

Fetch, parse and count are deterministic. The output of this project is the difference between runs, so non-determinism in parsing would surface as policy change and be indistinguishable from the real thing.
