/* WHY */

  Every argument about AI agents and the web runs on anecdote, because there
  is no public baseline for what sites actually declare. This builds one, in
  the open, and gives it away under CC0.

/* HONESTLY */

  One person, evenings and weekends. Every commit so far was written with
  Claude Opus 5 as a pair, and no model is anywhere near the measurement:
  fetch, parse and count are deterministic on purpose, because the product
  of the project is the difference between runs and a model's
  non-determinism would be indistinguishable from real policy change.

  Every headline figure here has been wrong on first measurement at least
  once. None of those were caught by tests. They were caught by finding a
  number implausible and checking it by hand. The ones still on the page
  survived that.

/* THANKS */

  Tranco, for a ranking you can cite by list id and reproduce.
  Every site publishing an llms.txt, a security.txt or a humans.txt, which
  is the only reason any of this was measurable.
